# 2018 990 Data

All data used to generate
[`model6`](https://nonprofit-open-data-collective.github.io/governance/reference/model6.md).
Contains raw 990 data, features, and factor scores.

## Usage

``` r
dat.2018
```

## Format

An object of class `data.table` (inherits from `data.frame`) with 64139
rows and 24 columns.
