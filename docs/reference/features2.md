# Features for Training Data

Training data used to generate factor model
[`model6`](https://nonprofit-open-data-collective.github.io/governance/reference/model6.md).
See Step 5 of
[`vignette("legacy-2018-model", package = "governance")`](https://nonprofit-open-data-collective.github.io/governance/articles/legacy-2018-model.md)
for detailed description of each of these features.

## Usage

``` r
features2
```

## Format

An object of class `matrix` (inherits from `array`) with 64139 rows and
12 columns.
