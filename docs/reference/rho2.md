# Training Polychoric Correlations

Polychoric correlations for
[`features2`](https://nonprofit-open-data-collective.github.io/governance/reference/features2.md).
Generated useing `psych::polychoric(features2)`.

## Usage

``` r
rho2
```

## Format

An object of class `matrix` (inherits from `array`) with 12 rows and 12
columns.
